idexal Os Connect is an AI Gateway, MCP Gateway, and Skills Gateway that lets organizations centrally manage models, tools, reusable skills, and access from one admin panel.

Use them from the AI client you already have. The idexal Os desktop app is optional.

## What each gateway provides

| Gateway | What your organization manages | How your client uses it |
| --- | --- | --- |
| AI Gateway | Approved models, provider credentials, usage, and supported spend limits | Model requests go through the AI Gateway |
| MCP Gateway | Shared service connections and tool access | Your agent discovers and calls authorized tools |
| Skills Gateway | Reusable skills assigned to people and teams | Your agent retrieves the skills it can use through idexal Os MCP |

MCP carries tools and skills, not model calls. A client plugin connects both with one sign-in.
