The idexal Os plugin for OpenCode 2 brings your organization's AI Gateway models and idexal Os MCP into a plain OpenCode install. You sign in once; OpenCode loads them every time it starts.

The [`opencode-idexal-os`](https://www.npmjs.com/package/opencode-idexal-os) package is published and ready to install. You do not need the idexal Os desktop app.

## Requirements

- OpenCode 2 with the integration, provider, and MCP plugin APIs. The plugin is tested with 2.0.26; OpenCode 1 is not supported.
- An idexal Os account and organization membership. An admin grants the models, skills, and connections you can use.

Check your installed version first:

```sh
opencode --version
```

Installing the plugin does not install or upgrade OpenCode.

## Install and sign in

<Steps>
<Step title="Install the plugin">

```sh
opencode plugin add opencode-idexal-os
```

</Step>
<Step title="Sign in">

```sh
opencode auth login idexalos
```

Choose **Browser**. Sign in to idexal Os, pick your organization and approve. OpenCode finishes signing in on its own.

On SSH or a machine without a browser, use `opencode auth login idexalos --method code`, open the link on any device and confirm the code.

</Step>
<Step title="Check what you got">

```sh
opencode auth list
opencode models | grep ipr_
opencode mcp list
```

Your AI Gateway models are listed as `ipr_…/gwm_…`. `idexal-os-cloud` gives the agent your organization's skills, plugins and connections. Connections your admin made available in other apps appear as `idexal-os-direct-<name>-<id>`.

</Step>
</Steps>

<AccordionGroup>
  <Accordion title="Sign out or switch organizations">

```sh
opencode auth logout idexalos
opencode auth login idexalos
```

Signing out also ends the idexal Os session and removes the models and MCP servers the plugin added. Pick the other organization on the approval page when you sign in again.

  </Accordion>
  <Accordion title="Self-hosted or enterprise idexal Os">

Point the plugin at your idexal Os API in `~/.config/opencode/opencode.json`:

```json
{
  "plugins": [
    { "package": "opencode-idexal-os", "options": { "apiBaseUrl": "https://api.idexal-os.example.com" } }
  ]
}
```

  </Accordion>
  <Accordion title="Only models, or only MCP">

Set `"providers": false` or `"mcp": false` in the plugin options.

  </Accordion>
  <Accordion title="No AI Gateway models listed">

The plugin shows the AI Gateway providers your organization grants you. Ask an admin to check **AI Gateway** in idexal Os Cloud. Models the catalog marks as deprecated are hidden.

  </Accordion>
  <Accordion title="Only MCP, without the plugin">

Add idexal Os MCP to OpenCode directly: [Connect OpenCode](/model-context-protocol/opencode).

  </Accordion>
</AccordionGroup>
