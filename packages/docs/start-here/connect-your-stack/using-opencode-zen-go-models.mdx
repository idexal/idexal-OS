OpenCode Zen and OpenCode Go models are provided by OpenCode, not idexal Os. If you have an OpenCode subscription or API key, connect the `OpenCode Go` provider in the idexal Os desktop app.

<Note>
OpenCode and idexal Os model subscriptions are separate. If you are unsure which one you have, see [idexal Os vs OpenCode models](/start-here/connect-your-stack/idexal-os-vs-opencode-models).
</Note>

## Connect OpenCode Go in idexal Os Desktop

1. Open idexal Os Desktop.
2. Click your avatar in the bottom-left corner.
3. Open `Settings`.
4. Go to `AI Providers`.
5. Click `Connect`.
6. Search for `opencode`.
7. Choose `OpenCode Go`.
8. Click `Connect` and enter your OpenCode API key when prompted.

<Frame>
  ![OpenCode Go provider in the Connect providers dialog](/images/opencode-go-connect-provider.png)
</Frame>

After the provider is connected, choose an OpenCode model from the model picker in a chat.

## Manage your OpenCode account

- Learn about OpenCode Go at [opencode.ai/go](https://opencode.ai/go).
- Manage your OpenCode account or authentication at [opencode.ai/auth](https://opencode.ai/auth).

If idexal Os says the OpenCode key is invalid or the model is unavailable, check your OpenCode account first. idexal Os does not manage OpenCode Go or OpenCode Zen billing.
