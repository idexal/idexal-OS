title: "Dashboards overview"
sidebarTitle: "Overview"
description: "What your idexal Os dashboard is and how to add apps to it."
---

A dashboard is a page of live, interactive apps in the desktop sidebar under **Dashboard**. It requires an idexal Os Cloud sign-in, and your deployment must have Dashboards turned on.

To add an app, ask idexal Os in chat for an app or dashboard of a Workflow's results. Try the draft preview, ask for changes, then choose `Save` to add it to your dashboard. Any signed-in member can do this when it is available to your org. Apps shared with you can be added from the dashboard too.

Apps built from chat display and explore results; they do not submit approvals or other writes.

To build your own MCP App widget, follow [Build an MCP App](/dashboards/build-an-mcp-app).
